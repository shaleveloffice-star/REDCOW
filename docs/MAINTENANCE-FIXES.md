## בדיקות

- `npm run lint`: TypeScript ללא פליטת קבצים, כולל בדיקת סמלים לא בשימוש.
- `npm test`: 32 בדיקות עם נתונים סינתטיים. בין היתר: מקביליות, כשל שמירה אחרי דיוור, הרשאות API, JWT, SEO, קבצי JSON, מדיה ומיקוד בחלוניות.
- `npm run build`: בניית production מקומית, כולל זיהוי Proxy.
- `npm run test:smoke`: מול שרת production מקומי בלבד. 49 דפים ממפת האתר נבדקו ל־200, H1 יחיד, title, description, canonical ויכולת אינדוקס. נוספו בדיקות כניסת אדמין, חמישה API מוגנים, הפניות ו־404 של סיפור שאינו קיים.
- דפדפן מקומי: דף הבית, סגירת חלונית ההכרזה, פתיחת חלונית הזמנה, מעגל Tab וחזרת המיקוד, וגם מעבר מתפריט מובייל לחלונית הזמנה ברוחב 390px. לא הופעלו קישורי הזמנה ולא נשלחו טפסים.

חלון מניעת הכפילויות של Resend נבדק מול [התיעוד הרשמי](https://resend.com/docs/dashboard/emails/idempotency-keys). ניסיון משלוח לא ודאי שעברו ממנו 23 שעות לא נשלח מחדש אוטומטית. בקשות חוזרות בתוך חלון ההתאוששות משתמשות באותו payload ובאותו מפתח.

## גבולות ואימות בפריסה

כתובות ה־API, מבני הבקשות והתשובות ושמות ההגדרות של הספקים נשמרו. בדיקות הספקים השתמשו בהדמיות ולא ב־Firestore, OpenAI, Blob או Resend החיים. אין בכך אישור להרשאות או להגדרות של deployment מסוים. כדי שהתיקונים יגיעו לאתר החי נדרשים פריסת הקוד ופרסום כללי Firestore, ואחריהם בדיקת שמירה וקריאה מול הסביבה החיה.

לא שונו קישורי ההזמנה הזמניים, בהתאם להנחיית בעל הפרויקט. תרגום אוטומטי לא הופעל. קבצים שסומנו בבדיקה כמועמדים בלבד לקוד ישן לא נמחקו בלי הוכחה שאינם משמשים אינטגרציה או תהליך אחר. נתונים קיימים עם כפילויות או שליחות ישנות במצב לא ודאי לא שונו אוטומטית.

אחסון JSON המקומי מתאים לשרת פיתוח יחיד. ב־Firestore שמירת קטגוריה ו־SEO אטומית; בשני קבצים מקומיים יש סנכרון ופיצוי על שגיאה, אך אין הבטחת טרנזקציה מול קריסת מחשב באמצע שתי הכתיבות.
